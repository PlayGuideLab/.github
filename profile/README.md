# PlayGuideLab

PlayGuideLab 构建面向游戏玩家的独立英文攻略与资料网站，整理兑换码、Wiki、攻略、游戏资料库和更新信息。

## 两套互补的建站模板

- **Anvil**（anvilwiki-next）：面向 Codes、Wiki、结构化资料和轻量攻略。
- **game-sites**：面向长篇指南、游戏资料库和规划工具。

模板是可复用的建站工具，不等于已经上线的网站。Anvil 内置虚构演示内容；模板 B 也有主要验证对象，不能仅凭代码存在就称为正式运营站。其他测试夹具也不计作产品站。

## 公开练手实例

目前唯一已登记的公开游戏练手站是 [Emberville Guide · janvas.xyz](https://janvas.xyz/)。它是使用 Anvil 的独立实例，不是模板本身；同一站点的预览地址不算第二个产品。

这些是游戏信息网站，不是游戏平台、在线试玩门户或游戏引擎，也不代表相关游戏的官方站点。公开研究仓与辅助工具不计入游戏站数量。
